# supervisor

## 功能简介

可插拔、低额度的任务监工 Skill：Executor 负责完成任务，Supervisor 决定审查时点，Reviewer 独立找错，Reconciler 去重并整理返工项。监工只读取必要证据，不重复完整执行。

## 如何启用

- 说“启动监工”进入默认推荐的终审模式。
- 说“轻量监工”“终审模式”或“严格监工”选择对应模式。
- 最好同时给出验收标准；未提供时由 AI 从任务要求提取并列出。

## 如何禁用

- 说“关闭监工”。
- 关闭只影响当前任务，不删除或修改其他 Skill。

## 如何使用

- “轻量监工”：只查高风险与验收缺口，1 个 Reviewer，最多 1 轮返工。
- “终审模式”：最终交付前审查一次，默认 1 个 Reviewer，最多 2 轮返工。
- “严格监工”：按阶段 Gate 检查，按风险选择 Reviewer，最多 3 轮返工。
- “重新审查”：只复查已修改范围和未解决项。
- “请按数学建模维度终审”：加载专用清单，检查题意、假设、模型、数据、求解、稳健性、图表、论文逻辑和可复现性。
- 结论固定为 `PASS`、`REVISE`、`BLOCK`。
- `PASS` 才能交付；`REVISE` 必须列出问题、证据、严重度和最小返工；`BLOCK` 必须暂停并列出解除条件。

## 推荐的询问方式 / 示例提示词

- “启动监工。验收标准是：……完成后只做终审。”
- “严格监工。每个阶段检查偏离、错误、风险和下一步返工要求。”
- “终审这份数学建模论文，不要重做，按九个维度给 PASS/REVISE/BLOCK。”
- “终审这个 Python 任务，只检查最终代码、测试输出和验收标准。”
- “严格监工这个数学建模小任务，在题意/假设、模型、数据、求解数值、敏感性、图表论文逻辑、可复现性 Gate 后再继续。”
- “关闭监工，继续执行当前任务。”

## 适用场景

- 复杂代码、研究、数据分析、论文和数学建模任务。
- 正式提交前的独立质量检查。
- 需要控制额度、不希望第二个 Agent 重复完整执行的任务。
- 普通 Python 修复、研究分析和论文定稿：优先终审模式。
- 数学建模、关键数值结果或正式投稿：使用严格监工。
- 探索性草稿、低风险单步任务：关闭或轻量监工。

## 注意事项

- Supervisor 是审查层，不自动替代主 Agent 修改、提交或发布。
- 没有证据的判断必须标为“待核实风险”。
- `BLOCK` 只用于关键问题；普通可修复问题使用 `REVISE`。
- 默认不启用多模型重复审查；只有严格模式且风险明确时才增加 Reviewer。
- 严格数学建模 Gate 至少覆盖：题意理解/假设、模型选择、数据处理、求解与数值正确性、敏感性/稳健性、图表与论文逻辑、可复现性；清单会进一步拆成九项。
- 数学建模经验必须在当前题目和当前数据上重新验证。

## 额度建议

- 低额度：关闭监工或轻量监工。
- 默认：终审模式，一次 Reviewer 审查，只有 `REVISE` 才返工。
- 高风险：严格监工；只在 Gate 风险不同或证据互补时增加 Reviewer，不做无意义多模型投票。
