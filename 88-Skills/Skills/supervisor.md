# supervisor

## 功能简介

可插拔的任务监工 Skill：主执行 Agent 负责完成任务，Supervisor 只检查任务偏离、验收标准、错误和高风险；优先返回问题与最小返工要求，不重复完整执行。

## 如何启用

- 说“启动监工”进入终审模式。
- 说“终审模式”或“严格监工”选择对应模式。
- 最好同时给出验收标准；未提供时由 AI 从任务要求提取并列出。

## 如何禁用

- 说“关闭监工”。
- 关闭只影响当前任务，不删除或修改其他 Skill。

## 如何使用

- “启动监工”：最终交付前审查一次，默认推荐。
- “终审模式”：低额度检查最终产物。
- “严格监工”：在计划、核心执行、验证和交付前检查。
- “请按数学建模维度终审”：加载专用清单，检查题意、假设、模型、数据、求解、稳健性、图表、论文逻辑和可复现性。
- 结论固定为 `PASS`、`REVISE`、`BLOCK`。

## 推荐的询问方式 / 示例提示词

- “启动监工。验收标准是：……完成后只做终审。”
- “严格监工。每个阶段检查偏离、错误、风险和下一步返工要求。”
- “终审这份数学建模论文，不要重做，按九个维度给 PASS/REVISE/BLOCK。”
- “关闭监工，继续执行当前任务。”

## 适用场景

- 复杂代码、研究、数据分析、论文和数学建模任务。
- 正式提交前的独立质量检查。
- 需要控制额度、不希望第二个 Agent 重复完整执行的任务。

## 注意事项

- Supervisor 是审查层，不自动替代主 Agent 修改、提交或发布。
- 没有证据的判断必须标为“待核实风险”。
- `BLOCK` 只用于关键问题；普通可修复问题使用 `REVISE`。
- 数学建模经验必须在当前题目和当前数据上重新验证。
