# mermaid-diagram

## 功能简介

`mermaid-diagram` 用于绘制 Mermaid 流程图、工作流图、架构图和概念关系图，特别适合生成可导入 ProcessOn 或 draw.io 的流程图草稿。

## 如何启用

- 任务中明确提到流程图、工作流图、Mermaid、ProcessOn 导入草稿或 draw.io 导入草稿时启用。
- 在执行前读取全局 Skill 源说明：`C:\Users\18928\.codex\skills\mermaid-diagram-skill\SKILL.md`。
- 数学建模工作区也保留副本：`C:\Users\18928\Desktop\数学建模研究室\skills\mermaid-diagram-skill`。

## 适用场景

- CUMCM/数学建模题目的总体流程图。
- 数据处理、模型求解、验证和论文证据链的流程表达。
- 需要先生成 Mermaid 源文件，再导入 ProcessOn 或 draw.io 手工美化的图。

## 注意事项

- 流程图节点必须绑定题面、数据、脚本、表格、报告或终审记录中的证据。
- 不用流程图替代模型证明、风险函数、统计检验或主体级验证。
- 2025C NIPT 项目的验证样例见 `C:\Users\18928\Desktop\数学建模研究室\projects\2025-CUMCM-C\outputs\figures\2025_c_modeling_diagram_usage.md`。
